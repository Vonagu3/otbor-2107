# Отбор в команды по программированию — сайт с формами

Статические страницы (опросник и диагностический срез). Ответы отправляются в таблицу `answers` проекта Supabase; если база не настроена или недоступна, форма сохраняет ответы файлом.

Эта папка публикуется целиком. **Не кладите сюда ключи ответов и другие материалы педагога.**

## 1. Supabase (один раз, ~10 минут)

1. Зарегистрируйтесь на https://supabase.com, нажмите **New project**. Регион любой, пароль базы сохраните.
2. Слева **SQL Editor → New query**, вставьте содержимое файла `для_педагога/supabase_setup.sql`, нажмите **Run**.
3. Слева **Project Settings → API**. Скопируйте **Project URL** и ключ **anon public** в файл `_config.js`:
   ```js
   window.OTBOR_CONFIG = {
     supabaseUrl: "https://xxxxxxxxxxxx.supabase.co",
     supabaseAnonKey: "eyJ...",
     table: "answers"
   };
   ```
   Ключ anon можно публиковать: с ним можно только добавлять ответы, читать их нельзя (это задано политиками в SQL).
4. Ключ **service_role** (секретный) впишите в `для_педагога/supabase.env` по образцу `supabase.env.example`. Он нужен только скрипту сбора на вашем компьютере.

## 2. GitHub Pages (один раз, ~5 минут)

Из папки `site` в терминале:

```bash
git init
git add .
git commit -m "Формы отбора"
gh repo create otbor-2107 --public --source=. --push
gh api -X POST repos/{owner}/otbor-2107/pages -f build_type=legacy -f 'source[branch]=main' -f 'source[path]=/'
```

Или через сайт GitHub: создать публичный репозиторий, загрузить файлы, затем **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/otbor-2107/`.

После любого изменения файлов: `git add . && git commit -m "..." && git push`.

## 3. Проверка

Откройте адрес сайта, заполните опросник тестовым именем, нажмите «Отправить ответы». В Supabase → **Table Editor → answers** должна появиться строка. Тестовые строки потом удалите там же.

## 4. Сбор ответов

На своём компьютере: `python3 для_педагога/собрать_ответы.py` — создаст `сводка_опросник.csv` и `сводка_срез.csv` с автопроверкой однозначных заданий.

## Файлы

- `index.html` — стартовая страница со ссылками.
- `01_опросник.html`, `02_срез.html` — формы.
- `_config.js` — адрес и ключ Supabase. `_common.js`, `_common.css` — общий код и стили.
- `practice/` — файлы для блока F (скачиваются со страницы среза).
